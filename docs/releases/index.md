
# Documentation Release History

## Version 1.0.0

**Release status:** Initial portfolio documentation release

**Description:**

Initial documentation for the Smart Expense Tracker application.

### Documentation introduced

- Product overview
- Installation guide
- Dashboard user guide
- API overview
- API endpoint inventory
- OpenAPI specification
- Interactive API reference
- API request and response examples
- API testing report
- API error reference
- API data models

### Known limitations

- Authentication is not consistently enforced across all expense endpoints.
- Passwords are stored as plain text.
- JWT signing secret is hard-coded.
- Some API response details still require verification.

### Documentation status

This release represents the initial documentation baseline. It does not indicate that the application is production-ready.
